# AGENTS.md

## Project

- Godot 4.7 (Mobile renderer) GDScript game targeting iOS with Apple Game Center real-time multiplayer. Flat layout: scripts and `Main.tscn` at repo root.
- No build system, no tests, no CI. Verification = headless Godot runs (commands below).
- Entry: `Main.tscn` (registered as main scene by uid in `project.godot`) → `main.gd`. `GameManager.gd` is an autoload singleton; all Game Center flow lives there (`authenticate()`, `request_match()`), triggered from `button.gd` `_on_pressed`.
- `.gd.uid` sidecar files are generated by Godot — keep them committed, never hand-create or delete them.

## Commands

Installed Godot binaries:

- `/Applications/Godot.app/Contents/MacOS/Godot` — 4.7.2, matches `config/features` in `project.godot`. Use this one.
- `/Applications/Godot-46.app/Contents/MacOS/Godot` — 4.6, wrong version for this project.

```sh
GODOT=/Applications/Godot.app/Contents/MacOS/Godot

# Import / refresh assets after adding files
$GODOT --headless --path . --import

# Syntax/type check a single script (exit code is the signal)
$GODOT --headless --path . --check-only --script res://GameManager.gd

# Smoke-run the game
$GODOT --headless --path . --quit-after 2
```

Known benign output (not failures): `Instantiated GKLocalPlayer used as default value` warning at startup; leaked ObjectDB/resources warnings at exit. Exit code 0 = pass.

## Game Center / GDExtension

- `addons/GodotApplePluginsGameCenter` is a **prebuilt binary** GDExtension — no source in this repo. It provides `GameCenterManager` and the `GK*` classes (`GKMatch`, `GKLocalPlayer`, `GKMatchmaker`, ...).
- Read the bundled class docs instead of guessing API signatures:
  `addons/GodotApplePluginsGameCenter/bin/GodotApplePluginsGameCenter.framework/Versions/A/Resources/doc_classes/*.xml`
  (also duplicated under `GodotApplePluginsGameCenter_x64.framework`).
- `addons/GodotApplePluginsRuntime` (SwiftGodot runtime) must stay installed — the `.gdextension` manifests declare it as a native dependency; removing it breaks iOS exports and macOS loading.
- On Linux/Windows the extension loads no-op stub libs (`.so`/`.dll`). Game Center behavior only exists on macOS/iOS — desktop editor runs cannot exercise matchmaking or auth.

## iOS export

- Single preset `iOS` in `export_presets.cfg`: bundle id `xogot.mateus.axolotl`, Game Center entitlement enabled, min iOS 16.0, portrait-only iPhone.
- `xogot/` holds iOS export artifacts: `Info.plist`, `game.entitlements`, `PrivacyInfo.xcprivacy`, plus `export-preset-migration-backup-v1/` (pre-migration copies) and `export-preset-migration.json` (migration version marker). Don't delete the backup.
- The editor in use is Xogot (`/Applications/Xogot.app`), recorded in `.godot/editor/project_metadata.cfg`. It also stores per-file UI state in the `[xogot]` section of `project.godot` — ignore that section when editing config by hand.
- Signing secrets (provisioning profile UUIDs, script encryption key) live in `.godot/export_credentials.cfg`, which is gitignored — never print or commit its contents.

## Conventions / gotchas

- `.gitignore` covers only `.godot` and `/android/`; `.gitattributes` forces LF for all text files. (Directory is not yet a git repo — `.git` absent as of writing.)
- Prefer the Godot editor/Xogot for changes to `project.godot` and `.tscn` files; hand-editing works but section formats are not all obvious.
- There are no lint/format/typecheck tools beyond Godot's own `--check-only`. Run it per changed script.
